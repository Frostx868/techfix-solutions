# TechFix Solutions

## Project Overview
TechFix Solutions is a responsive six-page technology repair website developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

## Features
- Responsive Design
- Bootstrap Framework
- Contact Form Validation
- Lazy Loaded Images
- Accessibility Features
- SEO Meta Tags
- Robots.txt
- XML Sitemap

## Pages
- Home
- About
- Services
- Portfolio
- Contact
- FAQ

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Google Fonts
